VAYORA — Travel Discovery & Trip Planner

OPEN THE WEBSITE
1. Extract the ZIP file.
2. Open the vayora-final folder in VS Code.
3. Open index.html in a browser, or use VS Code Live Server.
4. Keep style.css, script.js and the images folder beside index.html.

PROJECT FILES
- index.html: page structure and content
- style.css: visual design, typography, responsive layouts and interactions
- script.js: destinations, search, filters, wishlist, journey and budget logic
- images/: bundled travel photographs, including the custom Vayora hero image

FEATURES
- 20 destination entries (10 India, 10 international)
- Four featured destinations on the initial homepage
- Search and region/category filters
- Destination detail popup
- Wishlist saved in browser localStorage
- My Journey saved in browser localStorage
- Indicative budget calculator
- Explore dropdown and mobile navigation
- Responsive desktop, tablet and mobile layouts
- Keyboard support for destination cards and Escape-to-close popup/menu

PROJECT LIMITATIONS
This is a frontend student project. It does not book tickets or hotels, take payments,
use live prices, or connect to a live travel database. Destination and budget information
is sample content stored in JavaScript. Saved lists are stored in the current browser.
The photographs are bundled locally, so they do not require an external image service.
Google Fonts are optional; system fallbacks are provided.

DESTINATION IMAGE NOTE
Each of the 20 destination cards now has its own distinct, destination-matched visual asset; no destination reuses another card image. These are AI-created photographic-style illustrations, not documentary photographs.
